ส่วนที่ 1: Feature Engineering (ข้อ 1–4)
ข้อ 1 — Observe the Dataset
ต้องสำรวจว่าข้อมูลมีหน้าตาอย่างไร มีจำนวนเท่าไร ตัวแปรแต่ละตัวเป็นชนิดใด และมีข้อมูลสูญหายหรือไม่
สิ่งที่ต้องทำ
1.	โหลดไฟล์ heart.csv ด้วย Pandas
2.	ใช้ head() ดูตัวอย่างข้อมูล 5 แถวแรก
3.	ใช้ shape ตรวจสอบจำนวน Rows และ Columns
4.	ใช้ info() และ dtypes ตรวจสอบชนิดข้อมูล
5.	ใช้ isnull().sum() ตรวจสอบ Missing Values
6.	ตรวจสอบค่าผิดปกติที่อาจแทนข้อมูลสูญหาย เช่น ค่า 0 ในตัวแปรทางการแพทย์
สิ่งที่ต้องส่ง: ตารางแสดงโครงสร้างข้อมูล จำนวนระเบียน จำนวนตัวแปร ชนิดข้อมูล และสรุปการตรวจสอบ Missing Values พร้อมวิธีจัดการ
สำหรับไฟล์นี้ไม่จำเป็นต้องเติมค่า NaN โดยตรง แต่ควรพิจารณาจัดการค่า 0 ที่ไม่สมเหตุสมผลใน RestingBP และ Cholesterol โดยไม่ถือว่าทุกค่า 0 เป็น Missing Value
ข้อ 2 — Preprocess Numeric Data
ต้องเตรียมตัวแปรตัวเลขให้พร้อมสำหรับนำไปใช้ฝึกแบบจำลอง
สิ่งที่ต้องทำ
1.	ระบุตัวแปรเชิงตัวเลขทั้งหมด ได้แก่ Age, RestingBP, Cholesterol, FastingBS, MaxHR, Oldpeak
2.	ตรวจสอบค่า Min, Max, Mean, Median และการกระจาย
3.	จัดการค่าที่ไม่สมเหตุสมผลหรือ Missing Values ตามความเหมาะสม
4.	พิจารณาการปรับสเกล เช่น StandardScaler หรือ MinMaxScaler
5.	อธิบายเหตุผลว่าทำไมจึงเลือกวิธีนั้น
สิ่งที่ต้องส่ง: ตารางสถิติของตัวแปรตัวเลข + วิธี Preprocessing ที่เลือก + คำอธิบาย
คำแนะนำ: Decision Tree, Random Forest และ Gradient Boosting แบบต้นไม้ ไม่จำเป็นต้องปรับสเกลตัวเลขเป็นหลัก เพราะการแบ่งข้อมูลอาศัยค่าเกณฑ์ของตัวแปร สามารถเลือกใช้ค่าตัวเลขเดิมหลังจัดการข้อมูลผิดปกติได้
ข้อ 3 — Preprocess Categorical Data
ต้องแปลงข้อมูลหมวดหมู่จากข้อความเป็นตัวเลข เพราะโมเดลที่ใช้ผ่าน Scikit-learn ต้องรับข้อมูลในรูปแบบตัวเลข
สิ่งที่ต้องทำ
1.	ระบุตัวแปรหมวดหมู่ทั้ง 5 ตัว
2.	ตรวจสอบค่าที่ไม่ซ้ำกันของแต่ละตัวแปร
3.	เลือก Encoding ที่เหมาะสม
4.	แปลงข้อมูลด้วย One-Hot Encoding หรือ Binary Encoding
5.	ตรวจสอบผลลัพธ์หลังแปลงข้อมูล
แนวทางที่แนะนำ
ตัวแปร	วิธีแปลง
Sex	Binary Encoding (0/1)
ChestPainType	One-Hot Encoding
RestingECG	One-Hot Encoding
ExerciseAngina	Binary Encoding (0/1)
ST_Slope	One-Hot Encoding
สิ่งที่ต้องส่ง: รายชื่อตัวแปรหมวดหมู่ ตารางตัวอย่างก่อนและหลัง Encoding พร้อมอธิบายเหตุผลที่เลือกใช้
One-Hot Encoding เหมาะกับหมวดหมู่ที่ไม่มีลำดับเชิงตัวเลขชัดเจน และช่วยหลีกเลี่ยงการสร้างลำดับเทียม เช่น การกำหนดประเภทอาการเจ็บหน้าอกเป็น 0, 1, 2, 3
ข้อ 4 — Separate Training Data and Test Data
ต้องแบ่งข้อมูลสำหรับใช้ฝึกโมเดล และข้อมูลสำหรับวัดความสามารถในการทำนายข้อมูลที่ไม่เคยเห็น
สิ่งที่ต้องทำ
1.	กำหนด X เป็น Features ทั้ง 11 ตัว
2.	กำหนด y เป็น Target คือ HeartDisease
3.	แบ่งข้อมูลด้วย train_test_split()
4.	กำหนด random_state=42 เพื่อให้ทำซ้ำได้
5.	ใช้ stratify=y เพื่อคงสัดส่วนผู้มีและไม่มีโรคหัวใจ
ข้อ 5 — Decision Tree
สร้างแบบจำลองต้นไม้ตัดสินใจเพื่อจำแนกผู้ป่วยว่ามีโรคหัวใจหรือไม่
สิ่งที่ต้องทำ
1.	สร้างโมเดล DecisionTreeClassifier
2.	ฝึกโมเดลด้วย X_train และ y_train
3.	ทำนายผลด้วย X_test
4.	ประเมินประสิทธิภาพของโมเดล
5.	แสดง Confusion Matrix และ Classification Report
6.	วิเคราะห์ข้อดีและข้อจำกัดของโมเดล
สิ่งที่ต้องส่ง: ผลการทำนาย ตาราง Metrics, Confusion Matrix และคำอธิบายประสิทธิภาพ
ข้อ 6 — Random Forest
สร้างแบบจำลองโดยใช้ Decision Tree หลายต้นมาช่วยกันตัดสินใจ
สิ่งที่ต้องทำ
1.	สร้างโมเดล RandomForestClassifier
2.	กำหนดค่าพารามิเตอร์ เช่น n_estimators=100 และ random_state=42
3.	ฝึกโมเดลด้วย Training Set เดียวกับข้อ 5
4.	ทำนายผลด้วย Test Set
5.	ประเมินประสิทธิภาพด้วย Metrics เดียวกัน
6.	แสดง Confusion Matrix และ Classification Report
สิ่งที่ต้องส่ง: ผลการประเมินโมเดล Random Forest พร้อมคำอธิบาย
ข้อ 7 — Gradient Boost Trees
สร้างแบบจำลองที่ใช้ต้นไม้หลายต้นเรียนรู้ต่อเนื่องกัน โดยแต่ละต้นช่วยแก้ข้อผิดพลาดของแบบจำลองก่อนหน้า
สิ่งที่ต้องทำ
1.	สร้างโมเดล GradientBoostingClassifier
2.	กำหนดพารามิเตอร์ เช่น n_estimators, learning_rate, max_depth
3.	ฝึกโมเดลด้วย Training Set เดียวกัน
4.	ทำนายผลด้วย Test Set
5.	ประเมินประสิทธิภาพด้วย Metrics ชุดเดียวกัน
6.	แสดง Confusion Matrix และ Classification Report
สิ่งที่ต้องส่ง: ผลการประเมิน Gradient Boosting พร้อมคำอธิบาย
ข้อ 8 — Model Comparison and Selection
เปรียบเทียบผลลัพธ์ของโมเดลทั้ง 3 วิธี แล้วเลือกโมเดลที่เหมาะสมที่สุดสำหรับการทำนายโรคหัวใจ
สิ่งที่ต้องทำ
1.	รวบรวมผลประเมินจากโมเดลทั้ง 3 วิธี
2.	สร้างตารางเปรียบเทียบ Metrics
3.	สร้าง Barplot เปรียบเทียบประสิทธิภาพ (แนะนำ)
4.	ระบุโมเดลที่มีประสิทธิภาพดีที่สุด
5.	อธิบายเหตุผลในการเลือกโมเดล
สิ่งที่ต้องส่ง: ตารางเปรียบเทียบ 3 โมเดล + กราฟเปรียบเทียบ (แนะนำ) + บทสรุปโมเดลที่เลือก
