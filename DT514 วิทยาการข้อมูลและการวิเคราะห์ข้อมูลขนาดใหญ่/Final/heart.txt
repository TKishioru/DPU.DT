Heart Disease Dataset นี้ใช้สำหรับทำนายว่า ผู้ป่วยมีโรคหัวใจหรือไม่ โดยมี 11 Features สำหรับใช้ทำนาย และ `HeartDisease` เป็น Target

ความหมายของแต่ละ Feature

| Feature          | ความหมาย						| คำอธิบาย                                                                                           |
| ---------------- | -------------------------------| --------------------------------------------------------------------------------------------------|
| `Age`            | อายุ                            	| อายุของผู้ป่วย หน่วยเป็นปี                                                                         		|
| `Sex`            | เพศ                            	| เพศของผู้ป่วย โดยทั่วไป `M` = Male, `F` = Female                                                   		|
| `ChestPainType`  | ประเภทอาการเจ็บหน้าอก             	| `TA` = Typical Angina, `ATA` = Atypical Angina, `NAP` = Non-Anginal Pain, `ASY` = Asymptomatic    |
| `RestingBP`      | ความดันโลหิตขณะพัก               	| ความดันโลหิตขณะพัก หน่วย mmHg                                                                      	|
| `Cholesterol`    | คอเลสเตอรอล                     | ระดับคอเลสเตอรอลในเลือด หน่วย mg/dL                                                                	|
| `FastingBS`      | น้ำตาลในเลือดขณะอดอาหาร          	| `1` = มากกว่า 120 mg/dL, `0` = ไม่เกิน 120 mg/dL                                                   	|
| `RestingECG`     | ผลคลื่นไฟฟ้าหัวใจขณะพัก            | `Normal` = ปกติ, `ST` = มีความผิดปกติของ ST-T wave, `LVH` = ลักษณะที่บ่งชี้ภาวะหัวใจห้องล่างซ้ายโต 				|
| `MaxHR`          | อัตราการเต้นหัวใจสูงสุด              	| อัตราการเต้นหัวใจสูงสุดที่ตรวจวัดได้ หน่วยครั้งต่อนาที                                             				|
| `ExerciseAngina` | อาการเจ็บหน้าอกขณะออกกำลังกาย     	| `Y` = มี, `N` = ไม่มี                                                                              	|
| `Oldpeak`        | ค่าการเปลี่ยนแปลง ST depression   	| ค่าความแตกต่างของ ST segment จากการออกกำลังกายเมื่อเทียบกับขณะพัก ตามนิยามของชุดข้อมูล             			|
| `ST_Slope`       | ความชันของ ST segment          	| `Up` = ขึ้น, `Flat` = ราบ, `Down` = ลง                                                             	|
| `HeartDisease`   | ผลลัพธ์โรคหัวใจ                  	| `1` = มีโรคหัวใจ, `0` = ไม่มีโรคหัวใจ                                                             		|
