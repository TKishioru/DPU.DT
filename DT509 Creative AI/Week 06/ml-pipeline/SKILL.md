# ml-pipeline

## ขั้นตอน
1. เปิด [conventions](references/conventions.md) ก่อนเขียนโค้ดทุกครั้ง
2. รัน `python scripts/validate_data.py <ไฟล์ CSV ที่แนบ>` ก่อนเทรน
   - ถ้าผลขึ้น `FAIL` ให้หยุด รายงานผลจากสคริปต์ให้ผู้ใช้ และห้ามเทรนต่อ
   - ถ้าผลขึ้น `OK` ให้จดจำนวนแถวและค่าว่างของแต่ละคอลัมน์ไว้ใช้ในรายงาน
3. แบ่ง train/test ก่อนทำ scaling หรือเติมค่าว่างเสมอ ใช้ `test_size=0.2` และ `random_state=42`
4. เขียนโค้ดเป็นไฟล์แยกตาม conventions แล้วรันให้ได้ผลจริง
5. ส่งไฟล์ให้ผู้ใช้ดาวน์โหลด: `clean.py`, `train.py`, `evaluate.py`, `result.md`

## รูปแบบผลลัพธ์
`result.md` ต้องมีหัวข้อตามนี้ ครบทุกหัวข้อ
```
# ผลการทดลอง penguin-pipeline
## ข้อมูล
- จำนวนแถว: <จากสคริปต์ validate>
- ค่าว่างที่เติม: <คอลัมน์: จำนวน>
## โมเดล
- ชื่อโมเดลและพารามิเตอร์หลัก
## ผล
- accuracy (test): <ทศนิยม 3 ตำแหน่ง>
- confusion matrix: <ตาราง markdown แถว = ค่าจริง คอลัมน์ = ค่าที่ทำนาย>
## ข้อสังเกต
- ไม่เกิน 3 ข้อ
```

## ข้อห้าม
- **ห้าม**แก้หรือเขียนทับไฟล์ CSV ต้นฉบับที่ผู้ใช้แนบ ถ้าต้องบันทึกข้อมูลที่แก้แล้ว ให้ตั้งชื่อไฟล์ใหม่ เช่น `penguins_clean.csv`
- **ห้าม**ใช้ข้อมูลชุด test ในการคำนวณค่าเติมค่าว่างหรือ scaling
- ถ้าข้อมูลที่ต้องใช้ไม่มีในไฟล์ ให้บอกผู้ใช้ว่าขาดอะไร **ห้าม**สร้างข้อมูลขึ้นเอง
